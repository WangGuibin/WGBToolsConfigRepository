# Mac自带的Dictionary拓展

- 系统快捷键 ctrl + command + D

- Alfred 自己快捷键自定义 

都只是查单词而已

bash调用打开词典并查询该单词
```bash
open dict://$1
```

词典自定义 https://github.com/jjgod/mac-dictionary-kit
制作软件 https://github.com/jjgod/mac-dictionary-kit/files/4176459/DictUnifier.zip

词典下载 http://download.huzheng.org/zh_CN/

把下载好的词典解压或者制作好的词典放入 `/Library/Dictionaries`目录下,然后再词典偏好设置里勾选需要用到的词典即可
